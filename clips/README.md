# Excalidraw for the classroom - the feature clips

One short recording per feature. They are recorded on one machine, on one browser - a demonstration, not a benchmark.

| file | what it shows |
| --- | --- |
| `01-panels-on-the-canvas.mp4` | A code panel inserted from the main menu and a video panel dropped from the Files sidebar, both on the canvas: the code panel's own chrome (language picker, "Copy as code block", zoom) and the video player's controls, the panels floating free on the canvas and then selected. |
| `02-properties-panel-actions.mp4` | A code panel selected, with its controls in the properties panel on the left - Panel / Kind: code / State: Live, and the Actions: the camera, "Read the text" with its "indra" engine picker and the Bridge box - while the picture on the canvas carries none of them. |
| `03-crop-and-read.mp4` | The panel screenshotted, the region cropped with the mouse, and the read run as one action: the properties panel says "Reading the text…" while it reads, then "Read 12 lines with tesseract in 936 ms. indra was not used: the OCR sidecar is not running." - the engine it used, and why it did not use the one above it - and the text lands on the canvas, per line. |
| `04-the-crop-crops.mp4` | A video panel screenshotted from the properties panel, a real mouse drag of a crop handle so the picture shrinks to the cropped region, and the picture that lands on the canvas visibly smaller and showing only the cropped region. |
| `05-placement-flows.mp4` | The placement flow in order: the crop first, then the choice ("Place on a new page" and the page selector ribbon), then the target - the "place here" wireframe dragged onto the canvas and the popup handing the canvas back. |
| `06-presenter-view.mp4` | The teacher writes on the canvas and opens "Presenter view" from the main menu; the presenter view opens in its own window, waits for the editor, then shows the same canvas the teacher is teaching, and goes fullscreen with F. |
| `07-live-editor.mp4` | The panel's editor view is a real editor: text is selected with the mouse inside it, "Copy as code block" puts it on the clipboard, and it lands on the canvas as one code card; the language is changed to python from the panel's own bar, and the editor zooms to 150% inside the panel while the canvas zoom stays at 67%. |
| `08-what-is-mirrored.mp4` | The whole editor's window is mirrored by default; "Change what is mirrored" opens the whole window with a crop on it, and the crop the teacher draws is the only part the panel shows afterwards; the region is changed again, "Follow the cursor" is turned on and the region follows the pointer, and it is turned off again. |
| `09-run-code.mp4` | The panel's runtime picker, offering only the runtimes that are really on this machine (javascript, python, java, c, cpp - and not rust, which is not installed), and the panel's Run executing the draft in the teacher's workspace: "Run started: node excalidraw-bridge-snippet-code-run-1.js", the ten lines of output, and "Run finished with code 0." |
| `10-pages-frame-number-size.mp4` | The page's frame toggled on and drawn on the canvas, the page's number appearing at the foot of the page, the A4 portrait preset changing the page's shape, and "Export pages" producing the PDF at that shape. |
| `11-virtual-display.mp4` | The extension's presenter panel reports the virtual display it found ("a window goes on the virtual display Generic PnP Monitor (1920x1080 at 1920,0)"), and the two controls on it: "Move this editor to the virtual display" - which is the teacher's choice, nothing moves until it is pressed - and "Bring this editor back to this screen"; when it is pressed the editor's window really goes to the virtual display, filmed there, with the extension's own report of what it did. |
| `12-youtube-captions.mp4` | A YouTube panel playing YouTube's own player, and the captions' tier: this machine has no YouTube Data API key, so the tier that answers is the third one, and the panel says so - "no captions: the YouTube API key is not set and the public timedtext endpoint gave nothing back. Set excalidraw-bridge.youtubeApiKey to read them". |
| `13-the-code-card.mp4` | The markdown viewer's "Copy code" on a fenced block, pasted onto the canvas as one dark code card of monospace, highlighted text - not a row of plain bordered text boxes. |
| `14-the-file-sidebar.mp4` | The Files sidebar: the listing grouped by type, a markdown file picked and read in the viewer, a file that cannot be used listed with the reason why ("archive.zip - unknown file type"), and a video row dragged onto the canvas with a loading wireframe standing where the player will land. |
| `15-the-live-view.mp4` | The editor's own window mirrored into the panel as a live MJPEG stream: the picture follows the editor as the teacher moves through the file, and the panel's own state follows the file that is open. |
